## Glossaire HDQ

| Terme | Définition |
|---|---|
| **Ω:CONTEXT** | Fichier racine décrivant l'identité du projet |
| **Ω:DECISIONS** | Journal ADR des décisions architecturales |
| **Ω:DOCS** | Documentation vivante indexée (ce fichier) |
| **RULED** | Action couverte par une règle/skill/norme existante |
| **UNRULED** | Action sans règle — le LLM décide seul et signale |
| **Gap** | Norme manquante détectée par Rule-Gap Analysis |
| **σ-trigger** | Signal de déclenchement d'un Δ-point |
| **Ψ-dimension** | Dimension d'inspection lors d'un Δ-point |
| **ADR** | Architecture Decision Record |
