# Graveyard — Code et décisions retirés

> Ce dossier archive le code, les décisions, et les patterns qui ont été abandonnés.
> Chaque entrée documente POURQUOI l'élément a été retiré.

## Format

Pour chaque élément retiré, créer un fichier `[NOM]-[DATE].md` avec :

```markdown
# [Nom de l'élément retiré]

- **Date de retrait** : [DATE_ISO]
- **Raison** : [Pourquoi cet élément est retiré]
- **Alternative** : [Par quoi il est remplacé, si applicable]
- **Contenu archivé** : [Le code/la décision retirée]
```

## Pourquoi archiver ?

- Éviter de refaire les mêmes erreurs
- Documenter l'évolution des choix architecturaux
- Permettre de restaurer si nécessaire
